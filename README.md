# 云音乐工具箱 (CloudMusicTool)

网易云音乐 Android 客户端的 LSPosed 体验优化模块：去广告、精简界面、收敛弹窗、隐私加固。

## 1.1.0 新增

- 搜索广告净化、冷启动广告预加载裁剪
- 播放页提示治理、搜索热词轮播、播客/AI DJ 引导、小组件/推送引导、歌词页推广、云村/直播推广
- 剪贴板读取拦截、启动任务编排（云村/直播、剪贴板、启动编排默认关闭）
- 顶部频道真实删除：可只保留需要的频道，隐藏频道不可点击/滑动

## 功能

**广告拦截（默认开启）**：开屏广告、运营弹窗、更新弹窗、首页信息流、评论区、播放页、音频贴片/播客、广告上报与外跳。

**界面净化（默认开启）**：首页模块逐项隐藏、顶部频道保留、底部导航精简、启动延迟跳过、引导气泡/评分/VIP 弹窗治理、自动播放控制、头像挂件关闭。

**隐私（默认关闭）**：OAID 上报拦截、日志写盘屏蔽、启动任务黑名单、APM 上报抑制、统计上报观测、剪贴板读取拦截、启动任务编排。

## 兼容性

| 项 | 值 |
|---|---|
| 目标应用 | `com.netease.cloudmusic` 9.6.08 |
| Xposed API | libxposed API 102 |
| 系统要求 | Android 10+（minSdk 29） |

## 已知限制

- 部分 1.1.0 新功能已注册但未自然触发验证：搜索广告、播放页提示、播客/AI DJ、小组件/推送、歌词页推广。
- 侧栏抽屉精简暂不支持。
- 仅适配 9.6.08；版本升级后需重新体检挂载点。
- 不触碰 VIP/付费/版权/地区、青少年模式、登录/Cookie/风控。
