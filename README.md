# 云音乐工具箱 (CloudMusicTool)

网易云音乐 Android 客户端的 LSPosed 体验优化模块：去广告、精简界面、收敛弹窗、隐私加固。

## 功能

**广告拦截（默认开启）**：开屏广告跳过、运营弹窗屏蔽、更新弹窗拦截、首页信息流广告、评论区广告、播放页广告、音频贴片与播客广告、广告上报与外部 App 静默跳转。

**界面净化（默认开启）**：首页模块逐项隐藏（30 项真实 blockCode）、底部导航精简、启动延迟跳过、引导气泡/评分/VIP 弹窗治理、自动播放控制、头像挂件关闭。

**隐私（默认关闭）**：OAID 上报拦截、日志写盘屏蔽、启动任务黑名单、APM 上报抑制、统计上报观测。

## 兼容性

| 项 | 值 |
|---|---|
| 目标应用 | `com.netease.cloudmusic` 9.6.08 |
| Xposed API | libxposed API 102 |
| 系统要求 | Android 10+（minSdk 29） |

## 已知限制

- 顶部频道保留、侧栏抽屉精简当前版本暂不支持（已在 App 内置灰）。
- 网易云版本升级可能导致挂载点失效，届时需重新体检。
