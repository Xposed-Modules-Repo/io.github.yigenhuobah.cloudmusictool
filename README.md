# 云音乐工具箱 (CloudMusicTool)

网易云音乐 Android 客户端的 LSPosed 体验优化模块：去广告、精简界面、收敛弹窗、隐私加固。

## 1.2.0 新增

- **实验页（第 4 个 Tab）**：只读展示实际命中的 ABTest（key / 分组 / 来源 / 次数）。
- **白名单强开**：22 个 curated 体验 key，单 key 选择 `c/t/t1/t2/t3/t4`；已探测 key 可手动提升；黑名单 key 显示「禁止强开」。
- **一键恢复默认**：强开默认关闭，重启网易云生效。

## 功能

**广告拦截（默认开启）**：开屏广告、运营弹窗、更新弹窗、首页信息流、评论区、播放页、音频贴片/播客、广告上报与外跳、搜索广告、广告预加载。

**界面净化（默认开启）**：首页模块逐项隐藏、顶部频道真实删除、底部导航精简、启动延迟跳过、引导气泡/评分/VIP 弹窗治理、自动播放控制、头像挂件关闭、播放页提示、搜索热词、播客/AI DJ 引导、小组件/推送引导、歌词页推广。

**隐私（默认关闭）**：OAID 上报拦截、日志写盘屏蔽、启动任务黑名单、APM 上报抑制、统计上报抑制、剪贴板读取拦截、启动任务编排。

**实验（默认只读）**：只读观测 ABTest 命中；精确白名单强开体验类分组；VIP/付费/版权/音质/订单/地区/青少年/登录/Cookie/鉴权/风控/免流/免广告一律禁止。

## 兼容性

| 项 | 值 |
|---|---|
| 目标应用 | `com.netease.cloudmusic` 9.6.08 |
| Xposed API | libxposed API 102 |
| 系统要求 | Android 10+（minSdk 29） |

## 已知限制

- 部分新功能已注册但未自然触发验证：搜索广告、播放页提示、播客/AI DJ、小组件/推送、歌词页推广。
- 侧栏抽屉精简暂不支持。
- 实验强开可能导致界面异常；每次只开一个，可一键恢复默认。
- 仅适配 9.6.08；版本升级后需重新体检挂载点。
- 不触碰 VIP/付费/版权/地区、青少年模式、登录/Cookie/风控。
